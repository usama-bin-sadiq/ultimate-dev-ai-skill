# v3.0.0

## Major runtime and platform release

- Added strict JEV-bound execution with restart-safe approval validation.
- Added durable idempotent operations, cancellation, leases, recovery, policy, capability, path, and evidence enforcement.
- Added typed canonical workflow/catalog execution with an explicit Runtime capability-authorizer boundary.
- Added optional dependency-free MCP transport integration seams.
- Added provenance-aware project memory with safe context projection.
- Added governed self-evolution candidates with independent evaluation and receipt-only publication.
- Added provider-neutral evaluation tooling with traces, repeated trials, redaction, and no-provider honesty.
- Corrected release automation to use the root `VERSION` source of truth.

## Verification

- 665 Python tests passed.
- 18 JEV Node tests passed.
- 52 structure checks passed.

This release does not claim a literal 10/10 production architecture. Distributed
execution, native provider transports, full legacy catalog hydration, external
domain verifiers, tamper-evident storage, and governed canonical publication
remain deployment/host responsibilities.
