# Observation Protocol

## Candidate types

- Reusable workflow
- Skill improvement
- Agent improvement
- Simplification
- Cross-cutting principle
- No observation

A record qualifies only when a future task could use the lesson without the
original conversation. Include the smallest useful context, not a transcript.

## Append protocol

1. Read the live log.
2. Find the highest observation number.
3. Re-read immediately before writing.
4. Append the next unused number.
5. Re-read and verify uniqueness and required fields.
6. Never rewrite unrelated records during normal operation.

Use a separate reviewed procedure for archival, correction, or status changes.
