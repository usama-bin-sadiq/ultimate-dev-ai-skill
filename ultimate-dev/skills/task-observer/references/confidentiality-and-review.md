# Confidentiality and Review

## Confidentiality

Default to `open-source` only when the lesson contains no client, employer,
credential, private project structure, or identifying detail. Otherwise use
`internal` and keep the generalized principle separate from private context.

Never persist passwords, tokens, API keys, private URLs, hidden chain-of-thought,
or temporary debugging output.

## Review

Record the date of a real review in `last-review-date.txt`. Review candidates
for reuse, correctness, source quality, safety, duplication, and context cost.
The default action is `log and defer`; editing a skill requires a selected
observation, an explicit request, or an urgent in-session correction.
