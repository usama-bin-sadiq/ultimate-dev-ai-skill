# Internal Communications

Write communication that lets a specific audience make a decision or take the
next action without reconstructing the entire conversation.

## Method

1. **Identify audience and purpose** — inform, request a decision, assign work,
   escalate, or close the loop.
2. **Establish the source of truth** — use verified project state and label
   assumptions, estimates, and open questions.
3. **Lead with the decision** — put the conclusion, impact, and requested action
   before background detail.
4. **Separate facts from interpretation** — include dates, owners, metrics, and
   links or source references when available.
5. **Make ownership explicit** — every action needs an owner and due date or an
   explicit “unassigned”.
6. **Adapt the format** — executive brief, team update, meeting note, incident
   notice, or decision record; do not use one format for every audience.
7. **Check before sending** — names, numbers, dates, confidentiality, tone,
   accessibility, and approval requirements.

## Output shapes

- **Update:** status → progress → risks/decisions → next actions.
- **Decision memo:** decision → options → rationale → consequences → owner.
- **Meeting note:** purpose → attendees → decisions → actions → open questions.
- **Incident notice:** impact → current state → mitigation → update time → contact.

## Boundaries

Never invent metrics, commitments, approvals, or urgency. Do not expose secrets
or regulated personal data. Drafting is allowed; sending, publishing, or
changing an external system requires explicit host approval.
